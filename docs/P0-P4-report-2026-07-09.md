### 5. 根因分析

**缓存率 14.6% 的三层根因：**

1. **结构性瓶颈（56.4%）**：83%流量是爬虫，其中大部分被anti-bot拦截返回429+no-store，CF无法缓存。这些请求全部计入dynamic状态。**整体缓存率天花板约20%**（取决于爬虫占比波动）。

2. **真实用户缓存率不足（~40%）**：排除爬虫后，真实浏览器用户缓存率约40%，未达50%+目标。主要原因：
   - miss 9.1%：可缓存路径首次访问或Cache Rules覆盖不全
   - expired 7.8%：Edge TTL到期后无serving stale
   - none 4.0%：部分路径无缓存策略

3. **爬虫流量增长趋势**：07-05部署Cache Rules后，爬虫请求从6.6K/天暴增至12K/天，dynamic占比从48%→68%，直接拉低缓存率从24.1%→10.5%。

### 6. 优化方案

| 优先级 | 方案 | 预期效果 | 实现难度 |
|--------|------|----------|----------|
| P1 | 真实用户缓存率监控：CF Analytics按UA过滤，只看浏览器UA的缓存率 | 准确衡量 | 低 |
| P2 | 减少 miss：检查Cache Rules覆盖路径，补全遗漏的可缓存路径 | miss 9%→3% | 中 |
| P2 | serving stale：Cache Rules加 `serve_stale` 参数，expired请求先用旧缓存 | expired 7.8%→0 | 低 |
| P3 | 中间件Cache API：城市页用 `caches.default` 显式缓存 | 城市页缓存率提升 | 中 |
| P3 | anti-bot 429 响应优化：考虑用CF WAF规则替代Functions层拦截 | 429不经过Functions→不计入dynamic | 高 |

**结论**：整体缓存率14.6%看起来低，但83%流量是爬虫（不可缓存），真实用户缓存率约40%。优化重点应放在"减少miss + serving stale"，目标将真实用户缓存率提升至60%+。整体缓存率天花板约20%。

## P4: 广告解锁修复

### 1. Bug描述

广告解锁功能完全不工作——用户点击"看广告解锁"按钮后，弹窗出现但视频区域空白，进度条走完后永久卡住，权益永远不发放。

### 2. 根因

**致命bug：UnlockSession创建的video元素未挂载DOM + 未调用play()**

```
用户点击按钮
  → UnlockModal.show()
    → _createDOM() 创建弹窗DOM（含空的videoContainer div）
    → new UnlockSession(scene, rightType, successCb, fallbackCb)
      → handleUnlock()
        → 创建 video 元素
        → video.src = url
        → video.load()  ← 触发加载
        → ❌ video元素未添加到任何DOM节点（不可见）
    → _handleCanPlay() (canplaythrough触发)
      → ❌ 未调用 video.play()（视频不播放）
      → buttonState = 'playing'
      → _updateUI('playing') 显示空白的videoContainer
      → _startProgressTracking() 用Date.now()模拟进度条
    → video.ended 永远不触发（视频没在播放）
    → 解锁成功流程永远不执行
    → 权益永远不发放
```

### 3. 修复内容

| 文件 | 修改 |
|------|------|
| `js/ad-unlock/unlock-session.js` | 构造函数增加videoContainer参数；handleUnlock()将video元素insertBefore到容器；_handleCanPlay()增加video.play()调用；移除多余inline style |
| `js/ad-unlock/ui-components.js` | show()方法传入this._videoContainer给UnlockSession |
| `js/ad-unlock-loader.js` | import路径加?v=2确保缓存失效 |
| `index.html` | 删除重复CSS引用(v1+v2→仅v2)；loader.js版本v1→v2；sw.js?v=13 |
| `meeting-planner/index.html` | import路径加?v=2 |
| `sw.js` | 版本号v12→v13 |
| `functions/lib/constants.js` | CACHE_VERSION v12→v13 |
| `functions/city/city-template.js` | sw.js?v=13 |
